# 时间优先级与无票替代方案

更新时间：2026-11-02。当天/非当天优先级和30分钟窗口是用户的购票偏好，不是铁路售票规定。
每次实际执行重新读取当前日期和官方起售状态，不把旧会话的“今天”或默认查询日期沿用到新任务。

## 1. 先判定日期、起售状态和硬性限制
- 按行程所在地日期判断是否当天，中国境内使用Asia/Shanghai；跨午夜、任务恢复或未来任务触发后重新判定。
- 目标时间T取预期车次在用户实际出发站的计划发车时间；不是现在、始发站时间或下一班候选的时间。
- 非当天范围固定为T到T+30分钟（含边界），不因查下一班又无票就重新起算30分钟。
- 用户明确“只要该车次”“不接受顺延”、最晚出发/到达、预算及产品限制优先于默认策略；仅给预期车次不自动视为禁止本规则的短时替代。
- 起售状态按该日期、具体站间及车次核实，不能只按预售天数猜；未起售、已售罄、暂停售卖、已停售和停运不是同一状态。
- 查询尚未开售时，不按“无票”执行顺延，也不尝试提交尚不支持的候补。

## 2. 非当天：时间准确优先
1. 目标有符合用户与产品条件的可接受票，就购买目标，不主动顺延。
2. 目标无票时，仅检查目标发车后30分钟内、仍满足同日期同方向及用户限制的车次。
3. 窗口内有合规票时，按既有有座优先规则选择，通常取最接近目标的有座班次；只有窗口内有座全部不可用时才考虑允许的无座。
4. 目标及此窗口都没有可接受票时，立即转目标的候补方案，不购买更晚有票车次，即使后面40分钟或1小时的班次有座。
5. 候补默认保留目标车次；增加其他车次只限已接受的窗口和席别，不用“组合越多越好”扩张到任意时段或日期。
6. 候补不可用时明确原因及可用售前/售后方案，不能借故购买30分钟以后的票；用户明确改约束后才能扩大范围。
7. 不为了等远处有座而放弃时间窗口内的合法无座兜底；用户禁止无座时，则只按其允许席别判断无票并候补。

## 3. 当天：成行优先
1. 目标有可接受票就买目标，不为“当天成行”主动换到更晚车次。
2. 目标无票时，按发车时间向后查找可实际赶上、可检票且满足用户限制的车次；没有默认30分钟封顶。
3. 在允许的当日范围内优先查有座；有座都不可用再按原规则考虑无座。用户指定最晚时间时不得为有座无限向后找。
4. 不提前到用户未接受的更早班次，不跨日，不换站、不超预算或跨计次产品范围；无后续合规现票则进入可用候补方案。
5. 候补临近发车可能已截止，须查当前入口和兑现截止；不能承诺短时间内必定成功。
6. 提示最终班次与预期的时间差；用户给了硬性时限时，超限不能以“出行更重要”为由自行成交。

## 4. 未开售：预约购票
这里的“预约购票”指开售前登记购票需求，不是用已购计次票预约具体席位。
- 查起售时间，查看当前账号、乘车人、产品及平台是否有适用的预约服务。部分服务有资质、日期或线路限制，不能假定所有旅客都有入口。
- 有正式售前预约入口时，按当前页面填写日期、站间、车次、席别和乘车人，核对是否需要预支付、何时兑现/付款及失败处理，取得相应授权后提交。
- 核验预约记录和状态后只报告“预约购票需求已提交/待兑现”，不称为已出票。开售后未成功时再按实际可用入口转候补，不在售前伪造候补订单。
- 只有“购票信息预填”时，可先填写并保存需求，但明确这是预填，不是正式预约或占座；是否自动提交以当前功能为准，不默认承诺自动下单。
- 未到预约/预填开放时点时说明实际开放时间；需要到时继续执行则调用真实宿主调度并确认创建结果。无调度能力就说明未设置，不用无限等待或口头承诺代替。
- 不为此要求用户去未授权第三方平台注册或购买加速包；无官方适用入口时如实报告，不编造可操作按钮。

## 5. 已开售无票：候补购票
- 先确认已起售且没有合规现票；根据第2/3节决定先查短窗口替代，还是当天顺延，不一律跳过查询直接候补。
- 从当前车次/席别的“候补”入口添加被允许的组合，核对日期、方向、乘车人、席别、截止时间及可能的临时新增列车范围。
- 存在相关预填、预约或候补记录时先核对，避免重复需求。使用 [重复行程检查](duplicate-itineraries.md)，不把未兑现记录当作已经买到票。
- 普通票候补按当前页面核对预付款及付款期限；授权和预算已覆盖时继续，否则说明具体金额并确认，支付按宿主要求交接。
- 对计次票优先核对该产品是否有自己的候补/需求功能；产品无对应入口时明确说明。另开普通票候补需要另付票款，不默认扣计次次数，也不能静默切换。
- 页面显示“待支付”不能报告候补已生效；完成所需预付并核验有效候补状态后才报告“候补已提交/待兑现”。
- 只有兑现后再核验已支付车票或产品预约的实际行程、席别及席位，才能报告购票成功；兑现失败或终止须如实说明。
- 只选择一条当前执行路径；候补期间又购买替代票可能产生重复行程，须提示并核对原需求。不能擅自取消候补、旧票或预约。

## 6. 术语与验证边界
| 名称 | 适用时点和结果 |
| --- | --- |
| 预约购票 | 开售前登记需求，是否适用及何时兑现按对应服务；不等于已出票。 |
| 购票信息预填 | 开售前准备资料，开售时用于提交；保存预填不等于预约成功或已占座。 |
| 候补购票 | 已开售且目标无票后排队等待，需入口可用；待兑现不等于已购票。 |
| 计次票席位预约 | 已购产品的具体乘车班次预约，按产品可预约车次办理，不是售前预约购票。 |

## 7. 静态验收场景
| 条件 | 结果 |
| --- | --- |
| 非当天目标18:00无票，18:30有合规票 | 可选18:30；恰好30分钟属于窗口内。 |
| 非当天目标18:00和窗口内均无票，18:31才有票 | 不选18:31，转目标候补。 |
| 非当天先查18:20无票，18:45有票 | 窗口不滚动，18:45不可选。 |
| 当天目标18:00有票，18:10也有票 | 买目标18:00，不主动顺延。 |
| 当天目标无票，18:45有合规票 | 可顺延18:45；用户要求18:30前出发则不可。 |
| 用户只接受目标车次 | 不论当天与否均不换车，按开售状态走预约或候补。 |
| 目标尚未开售，页面有适用售前预约 | 走预约购票，不称作已候补。 |
| 未开售但只有预填入口 | 保存预填并标明结果，不假称已预约或已自动提交。 |
| 已开售、无票、有候补入口 | 按窗口策略转候补，核验费用与有效状态，不报告出票。 |
| 计次预约无票且无产品候补入口 | 不假造候补功能；普通票候补有额外票款，先说明并获授权。 |

规则及场景仅静态核对；本次未创建真实预售预约、预填或候补订单，不将其表述为已端到端实测。
